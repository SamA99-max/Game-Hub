# Ursina-games
All these games are created using one graphics engine called ursina this originally was to test out how good I am in Python, but like this game_engine project (i like to call it) where i created like a small game hub myself and recreated some iconic games just without those huge file sizes and extra permissions ;)

Make sure to have the library: ursina and version: 7.0.0
And install the folder as-it-is and run the main.py where you'll find a "blueprint" on where which file should be.

**Chess**

You can click each piece to see where it can move this game doesn't have en passent or promotion to any other piece than a queen (just take the best piece and go :3) )
you can move with W,A,S,D,C,V,U,O,Q,E with B you can go to the Blue side and with H to the Red side with R you can go to the default camera position
Checks and check mates will be highlighted and draw doesn't exist ( in any Form)
****

**Snake**

This is the Snake Xenzia game
you can select your snakes speed at the beginning with 1 being the slowest and 5 the highest
with all arrows you can move in all directions and eat the apples ( a red pixel)
****

**Tic** **Tac** **Toe**

**Pong**

inspired by the first ever Video-Game ever.
Firstly select (with your keyboard) 1 for single player and 2 for multiplayer if you select 1 choose the difficulty to 1-5
play with arrow up and arrow down (single player and the left paddle in multiplayer) and W,S keys (in multiplayer for the right paddle
